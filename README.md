# AI Energy Notes

一個以純 HTML / CSS / JavaScript 製作的靜態技術筆記網站。

## 專案特色
- 可直接部署至 GitHub Pages
- 使用 `AGENTS.md` 定義 AI 開發規則
- 每個技術主題使用獨立頁面
- 具有可重複使用的頁面模板
- 響應式設計

## 本地開啟
直接用瀏覽器開啟 `index.html` 即可。

## GitHub Pages
1. 將整個資料夾內容上傳到 GitHub repository。
2. 到 Settings → Pages。
3. Source 選擇 Deploy from a branch。
4. Branch 選 `main`，資料夾選 `/(root)`。
5. 儲存後等待 GitHub Pages 發布。

## 新增內容
先閱讀 `AGENTS.md`，再使用 `templates/page-template.html` 建立新頁面。
